# Loy Gold Price

最小 Windows 黄金价格条。显示招行**客户买入价、客户卖出价**（人民币元/克），以及**国际现货黄金 XAU/USD**（美元/金衡盎司），不含行情图或交易功能。

## 使用

从源码下载后先执行 `./build.ps1`，再运行生成的 `bin/LoyGoldPrice.exe`，免安装，需要 Windows 10/11 自带的 .NET Framework 4.8。源码仓库不包含编译后的 EXE 或本地诊断文件。

- 每 10 秒刷新招行黄金账户报价，无需账号、Cookie 或密钥。
- 右侧显示 `XAU 4030.61` 这样的国际现货价格，与左侧招行“入 / 出”保持相同窗口高度。悬停查看单位、报价时间、来源和昨收参考。两种行情独立刷新、判断过期、保留旧价，单边失败不影响另一边。
- 价格条只显示“入 / 出”。按接口涨跌方向：正数红、负数绿、零为金色；涨跌字段缺失或无效时为金色，数据失效时优先显示灰色。
- 优先放在主任务栏开始按钮左侧的空白处，避开小组件；空间不足、左对齐、自动隐藏或无法识别时，显示在工作区右下角。
- 右键：立即刷新、自动停靠、切换可拖动悬浮条、始终置顶、退出。托盘图标也提供同一菜单。
- “始终置顶”默认勾选，悬浮和停靠模式均可切换；取消后不会被定时更新强制恢复。此开关本次运行有效，重新启动恢复默认。
- 悬停查看接口时间和状态。灰色代表报价暂停、非交易日、接口失败或数据过期，并不单独表示休市。
- 失败时保留上次报价；未取得过报价则显示 `--.--`，不会用估算价格冒充招行报价。
- 全屏窗口位于前台时自动停靠模式隐藏价格条。退出后不留后台进程；不修改系统任务栏，不自动设置开机启动。

## 编译

在 PowerShell 执行 `./build.ps1`。使用 Windows 自带的 C# 编译器，不需要 NuGet、额外 SDK 或联网安装依赖。

应用和托盘使用原创金条图标，内嵌于 EXE，无需附带图片文件。`assets/gold.ico` 包含 16～256 像素多种尺寸；`assets/gold.png` 为预览，执行 `./assets/GenerateIcon.ps1` 可重新生成。

诊断：`bin/LoyGoldPrice.exe --probe <输出文本绝对路径>` 读取一次真实报价并退出；`--smoke <输出前缀绝对路径>` 启动界面、读取一次、保存窗口自身 PNG 和状态文本后退出。

## 数据与限制

POST `https://mbmodule-openapi.paas.cmbchina.com/product/v1/func/market-center`，表单参数 `params=[{"prdType":"H","prdCode":""}]`。读取 `FQAMBPRCZ1.zBuyPrc`（客户买入）、`zSelPrc`（客户卖出）、`NowTime`、`MarketDay` 和 `QuotedPrice`。

国际行情读取新浪财经 `https://hq.sinajs.cn/list=hf_XAU`，携带新浪财经 Referer。`hf_XAU` 是伦敦金现货报价，不使用 COMEX 黄金期货替代。读取最新价、昨收参考、日期和时间（北京时间），涨红跌绿持平金色；报价时间超过 2 分钟或请求失败时变灰。非官方公开接口可能限流或调整字段，休市期间保留的报价会按过期处理。国际价不换算成人民币，不与招行昨收基准混用。

该接口无公开的开发者稳定性承诺，可能限流或变更。接口 `NowTime` 显示为北京时间，但不能据此保证底层价格的实际撮合时刻。程序不额外扣减费用，最终价格和手续费以招行 App 为准。Windows 任务栏的 UI Automation 布局也可能随系统更新变化，无法识别时回退悬浮显示。

### 昨收颜色基准的验证范围

颜色使用 `zDvlCur` 的正负方向。2026-10-27 多次真实采样中，`买入价 - zDvlCur` 一直为 866.00（例如 865.96 - (-0.04)、865.53 - (-0.47)），因此将该字段推断为相对昨收参考的涨跌额。没有找到该字段的官方定义，也尚未与招行 App 同时核对；提示中会标明这是按接口涨跌反推的昨收参考。没有把启动价、上次刷新价格、上金所价格或国际金价当作招行昨收。

接口只提供这一项涨跌额，没有独立的昨收卖出价，故“入 / 出”共用这一方向，不表示已分别验证两个昨收基准。若银行调整买卖点差，两个价格各自相对昨收的方向可能不同。

验证：`./test.ps1` 检查正负方向、持平、缺失/无效字段与失效变灰优先级。
