# Loy Gold Price

最小 Windows 行情价格条。显示招行**客户买入价、客户卖出价**（人民币元/克）、**国际现货黄金 XAU/USD**（美元/金衡盎司），以及 **513110 纳指100 ETF 场内现价**（人民币元/份），不含行情图或交易功能。

## 使用

从源码下载后先执行 `./build.ps1`，再运行生成的 `bin/LoyGoldPrice.exe`，免安装，需要 Windows 10/11 自带的 .NET Framework 4.8。源码仓库不包含编译后的 EXE 或本地诊断文件。

- 每 10 秒刷新招行黄金账户报价，无需账号、Cookie 或密钥。
- 右侧依次显示国际现货价格和 513110 纳指100 ETF。ETF 分两行：第一行如 `513110 2.285 净溢 +9.78%`，第二行如 `净 2.0815(11-18) 估≈2.0379(美股11-19)`。现价三位小数、净值与参考估值四位小数。净值后为净值日期，估值后为所用纳指100的美国交易日期。悬停查看完整日期、行情时间、来源、计算口径及相对估值的溢价率。行情和净值每 10 秒独立刷新，估值所用指数和汇率每 60 秒查询；单路失败不影响其他行情。
- 价格条只显示“入 / 出”。按接口涨跌方向：正数红、负数绿、零为金色；涨跌字段缺失或无效时为金色，数据失效时优先显示灰色。
- 优先放在主任务栏开始按钮左侧的空白处，避开小组件；空间不足、左对齐、自动隐藏或无法识别时，显示在工作区右下角。
- 右键：立即刷新、自动停靠、切换可拖动悬浮条、始终置顶、退出。托盘图标也提供同一菜单。
- “始终置顶”默认勾选，悬浮和停靠模式均可切换；取消后不会被定时更新强制恢复。此开关本次运行有效，重新启动恢复默认。
- 悬停查看接口时间和状态。灰色代表报价暂停、非交易日、接口失败或数据过期，并不单独表示休市。
- 失败时保留上次报价；未取得过报价则显示 `--.--`，不会用估算价格冒充招行报价。
- 全屏窗口位于前台时自动停靠模式隐藏价格条。退出后不留后台进程；不修改系统任务栏，不自动设置开机启动。

## 编译

在 PowerShell 执行 `./build.ps1`。使用 Windows 自带的 C# 编译器，不需要 NuGet、额外 SDK 或联网安装依赖。

### GitHub 自动打包

- 推送分支、提交 PR 或在 [Actions](https://github.com/LoyWork/Loy_GoldPrice/actions/workflows/build.yml) 中手动运行 `Build Windows package`，会自动执行测试、编译并打包。
- 成功后，在该次运行底部的 Artifacts 下载 `LoyGoldPrice-windows-x64`，其中包含程序 ZIP 和 `SHA256SUMS.txt` 校验文件，保留 30 天。下载 Actions 产物需要登录 GitHub。
- 推送 `v*` 标签（例如 `v1.0.0`）时，还会自动创建对应的 [GitHub Release](https://github.com/LoyWork/Loy_GoldPrice/releases)，上传相同的 ZIP 和校验文件；重新运行会替换该标签下的同名附件。无需配置额外密钥。
- 解压 `LoyGoldPrice-windows-x64.zip` 后运行 `LoyGoldPrice.exe`，适用于 Windows 10/11 x64，需要 .NET Framework 4.8。

本地也可以依次执行 `./test.ps1`、`./build.ps1`、`./package.ps1`，打包结果位于 `work/package/`。

应用和托盘使用原创金条图标，内嵌于 EXE，无需附带图片文件。`assets/gold.ico` 包含 16～256 像素多种尺寸；`assets/gold.png` 为预览，执行 `./assets/GenerateIcon.ps1` 可重新生成。

诊断：`bin/LoyGoldPrice.exe --probe <输出文本绝对路径>` 读取一次真实报价并退出；`--smoke <输出前缀绝对路径>` 启动界面、读取一次、保存窗口自身 PNG 和状态文本后退出。

## 数据与限制

POST `https://mbmodule-openapi.paas.cmbchina.com/product/v1/func/market-center`，表单参数 `params=[{"prdType":"H","prdCode":""}]`。读取 `FQAMBPRCZ1.zBuyPrc`（客户买入）、`zSelPrc`（客户卖出）、`NowTime`、`MarketDay` 和 `QuotedPrice`。

国际行情读取新浪财经 `https://hq.sinajs.cn/list=hf_XAU`，携带新浪财经 Referer。`hf_XAU` 是伦敦金现货报价，不使用 COMEX 黄金期货替代。读取最新价、昨收参考、日期和时间（北京时间），涨红跌绿持平金色；报价时间超过 2 分钟或请求失败时变灰。非官方公开接口可能限流或调整字段，休市期间保留的报价会按过期处理。国际价不换算成人民币，不与招行昨收基准混用。

ETF 行情读取新浪财经 `https://hq.sinajs.cn/list=sh513110`，携带同一 Referer。513110 为华泰柏瑞纳斯达克100 ETF（QDII），显示上海市场的场内交易现价，不是基金净值或纳斯达克指数点位。按逗号分隔的字段从 0 起计，读取字段 3（现价）、2（昨收）、30（日期）、31（北京时间）；涨红跌绿持平金色，超过 2 分钟或请求失败时变灰，休市时保留旧价。未取得有效现价时显示 `--.---`。

单位净值独立读取新浪财经 `https://hq.sinajs.cn/list=f_513110` 的字段 1（单位净值）及 4（净值日期），不使用累计净值。参考溢价率为 `(现价 / 已公布单位净值 - 1) × 100%`，保留两位小数，负数表示折价。QDII 净值公布有延迟，此值并非实时估值溢价率或 IOPV 溢价率。缺少现价、净值或净值日期晚于行情日期时显示 `--%`；读取失败保留旧净值并将净值及溢价率变灰，日期异常或净值超过 7 个自然日也变灰。已公布净值不按实时行情的 2 分钟规则失效。

参考估值由程序计算：`已公布单位净值 ×（纳指100最新价 / 净值日指数收盘）×（USD/CNY最新价 / 净值日汇率收盘）`。指数与美元人民币行情及最近一个月的日线来自 Yahoo Finance 的 chart 接口（`^NDX`、`CNY=X`），指数交易日期按美国东部时区、汇率日线按数据源伦敦时区处理，包含夏令时。每次净值更新后自动切换基准日，累计计算跨多个交易日的变化。两路都必须有净值当日的有效收盘，缺少基准不会套用其他日期，而是显示 `估≈--.----`。

`估≈` 是基于指数及汇率变动的模型参考值，并非基金官方净值或 IOPV；未计基金实际持仓、现金、费用、分红、跟踪误差及实际估值汇率差异。美股休市时使用最近的指数行情，不推演盘后或期货涨跌，汇率可继续更新，因此不能视作中国盘中资产的实时公允价格。悬停显示指数、汇率各自时间以及 `(现价 / 参考估值 - 1) × 100%`；第一行的“净溢”仍以已公布净值计算。估值请求失败保留旧行情并变灰；数据获取超过 3 分钟、指数或汇率报价超过 4 个自然日、时间异常、净值失效时也变灰。数据源为非官方公开接口，无可用性保证。

该接口无公开的开发者稳定性承诺，可能限流或变更。接口 `NowTime` 显示为北京时间，但不能据此保证底层价格的实际撮合时刻。程序不额外扣减费用，最终价格和手续费以招行 App 为准。Windows 任务栏的 UI Automation 布局也可能随系统更新变化，无法识别时回退悬浮显示。

### 昨收颜色基准的验证范围

颜色使用 `zDvlCur` 的正负方向。2026-10-27 多次真实采样中，`买入价 - zDvlCur` 一直为 866.00（例如 865.96 - (-0.04)、865.53 - (-0.47)），因此将该字段推断为相对昨收参考的涨跌额。没有找到该字段的官方定义，也尚未与招行 App 同时核对；提示中会标明这是按接口涨跌反推的昨收参考。没有把启动价、上次刷新价格、上金所价格或国际金价当作招行昨收。

接口只提供这一项涨跌额，没有独立的昨收卖出价，故“入 / 出”共用这一方向，不表示已分别验证两个昨收基准。若银行调整买卖点差，两个价格各自相对昨收的方向可能不同。

验证：`./test.ps1` 检查正负方向、持平、缺失/无效字段与失效变灰优先级。
